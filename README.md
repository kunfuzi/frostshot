# Frostshot

Бесплатная кроссплатформенная программа для скриншотов. Быстрая, лёгкая, без рекламы и облачной привязки. Написана на Rust.

По хоткею замораживаются все мониторы сразу. Выделяешь область на любом из них, размечаешь и копируешь в буфер или сохраняешь в PNG.

## Возможности

- Оверлей сразу на всех мониторах, корректно работает с разным разрешением и масштабом (Per-Monitor DPI v2).
- Выделение рамкой или лассо. Shift + протягивание добавляет область, Alt + протягивание вырезает её. Всё за пределами выделения на снимке становится прозрачным.
- Клик без протяжки выделяет весь монитор.
- Лупа у курсора: координаты и цвет пикселя.
- Разметка: карандаш, маркер, линия, стрелка, прямоугольник, закрашенный прямоугольник, эллипс, текст, счётчик 1-2-3, пикселизация. Цвет, толщина колесом мыши, отмена и повтор.
- Скрыть личные данные (H): Frostshot распознаёт текст на выделении и сам пикселизирует почту, телефоны, номера карт (с проверкой по Луну), ключи и токены, пароли после «пароль:». Всё локально, без интернета.
- Копировать текст с выделения (Ctrl+Shift+C): распознавание встроенными средствами Windows.
- Линейка (R): расстояние в пикселях и проекции по осям.
- Закрепить снимок поверх окон (P): тащится мышью, колесо масштабирует, двойной клик закрывает.
- Уведомление после копирования и сохранения: клик заново открывает снимок с редактируемой разметкой.
- Проект `.frost`: снимок и разметка в одном файле, открывается для доработки.
- В Windows может работать обработчиком PrintScreen и Win+Shift+S (регистрация в настройках, без прав администратора).
- Ctrl+C или Enter копирует в буфер, Ctrl+S сохраняет через диалог, Ctrl+Shift+S сразу пишет в папку по умолчанию.
- Живёт в трее и не использует глобальные хуки клавиатуры и мыши, поэтому не тормозит систему.

## Клавиши

| Клавиша | Действие |
|---|---|
| PrintScreen, Ctrl+Shift+F12 | Сделать скриншот |
| V / L | Рамка / лассо |
| 1-9, 0 | 1 карандаш, 2 маркер, 3 линия, 4 стрелка, 5 прямоугольник, 6 текст, 7 пикселизация, 8 закрашенный прямоугольник, 9 эллипс, 0 счётчик |
| Shift при рисовании | Линия под 45°, квадрат, круг |
| Счётчик (0) | Нажать на место номера и тянуть к цели; с Shift наоборот, от цели к номеру; клик ставит кружок без выноски |
| Колесо мыши | Толщина |
| Ctrl + колесо, Ctrl+0 | Приблизить замороженный экран к курсору (до 1600%), вернуть 100% |
| Средняя кнопка | Сдвинуть увеличенный вид |
| Ctrl+Z | Отменить |
| Ctrl+Shift+Z, Ctrl+Y | Повторить |
| P | Закрепить поверх окон |
| H | Скрыть личные данные |
| Ctrl+Shift+C | Копировать текст с выделения |
| R | Линейка |
| Ctrl+C, Enter | Копировать и закрыть |
| Ctrl+S / Ctrl+Shift+S | Сохранить с диалогом / сразу |
| Правый клик | Сбросить выделение, повторный клик закрывает |
| Esc | Закрыть |

## Windows 11 и PrintScreen

Если в системе включено «Использовать клавишу PrtScn для открытия Ножниц», клавишу забирает Windows. Выключить: Параметры > Специальные возможности > Клавиатура. Пока параметр включён, работают Ctrl+Shift+F12 и клик по иконке в трее.

## Настройки

Файл `config.toml` лежит в `%APPDATA%\Frostshot\config\` на Windows, `~/Library/Application Support/Frostshot/` на macOS и `~/.config/frostshot/` на Linux. В нём задаются хоткеи, папка для сохранения, последний цвет и толщина.

## Сборка

```bash
cargo build --release
```

Самопроверка без окон (реальный захват плюс программный сценарий, кадры сохраняются в PNG):

```bash
cargo run -- --selftest selftest-out
```

## Платформы

Сейчас поддерживается Windows. Следующие на очереди macOS и Linux X11, после них Wayland через xdg-desktop-portal.
